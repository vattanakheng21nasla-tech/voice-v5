# 🎙️ Voice-V5 Pro: កម្មវិធីថតសម្លេងវៃឆ្លាត & កំណត់ហេតុរដ្ឋបាល

កម្មវិធីថតសម្លេងកម្រិតអាជីព (Professional Voice Studio) ដែលត្រូវបានរចនាឡើងយ៉ាងពិសេសសម្រាប់ស្ថាប័នរដ្ឋ ក្រុមហ៊ុន និងការងារទូទៅ ស្របតាមទម្រង់លិខិតរដ្ឋបាលស្តង់ដាររបស់ក្រសួងមហាផ្ទៃ និងរាជរដ្ឋាភិបាលកម្ពុជា។

---

## 🌟 មុខងារសំខាន់ៗទាំង ៥ (Features)

### ១. មុខងារថតសម្លេង & បម្លែងជាអក្សរ (Unlimited Recording & Low Storage)
* **កូដិកទំនើប Opus 48kHz (WebM/Opus)**: គុណភាពសម្លេងច្បាស់ល្អដូចក្នុងស្ទូឌីយោ ថតដោយស្វ័យប្រវត្តគ្មានដែនកំណត់ម៉ោង។
* **សុីទំហំផ្ទុកតិចបំផុត**: ត្រឹមតែ ~12 MB ទៅ 14 MB ក្នុង ១ ម៉ោង (សន្សំសំចៃទំហំជាង WAV រហូតដល់ 40 ដង)។
* **Live Speech-to-Text (STT)**: និយាយភ្លាម អក្សររត់ចេញភ្លាមៗ (Realtime Stream) គាំទ្រភាសាខ្មែរ (`km-KH`) និងភាសាអង់គ្លេស (`en-US`)។
* **Waveform Visualizer**: បង្ហាញបន្ទាត់រលកសម្លេង Oscilloscope ផ្ទាល់តាម Web Audio API។

### ២. មុខងារ Live Translation (បកប្រែផ្ទាល់ភ្លាមៗ)
* ពេលលោកអ្នកកំពុងនិយាយជាភាសាខ្មែរ កម្មវិធីនឹងធ្វើការបកប្រែពាក្យសម្តីរបស់អ្នកភ្លាមៗទៅជាភាសាគោលដៅ (Dual Screen Subtitles)។
* គាំទ្រភាសា៖ អង់គ្លេស (English), បារាំង (Français), ចិន (Chinese), ជប៉ុន (Japanese), ថៃ (Thai), វៀតណាម (Vietnamese), កូរ៉េ (Korean)។
* មានប៊ូតុង Copy ការបកប្រែដោយចុចតែម្តង។

### ៣. មុខងារទម្លាក់ឯកសារចូល & ចែករំលែក Link Wi-Fi / QR Code
* **Drag and Drop**: អាចទម្លាក់ឯកសារសម្លេង (MP3, WAV, M4A, OGG, WebM) ឬឯកសារ (PDF, DOCX, TXT) ចូលបានយ៉ាងងាយស្រួល។
* **Audio Player**: ចាក់ស្តាប់សម្លេងឡើងវិញ អាចពន្លឿនល្បឿនបាន (0.75x, 1.0x, 1.25x, 1.5x, 2.0x) និងទាញ seek bar ទៅវិនាទីដែលចង់ស្តាប់។
* **ចែករំលែក Link ប្រើប្រាស់រួមគ្នា**: បង្កើត Link ក្នុងបណ្តាញ Wi-Fi និង QR Code សម្រាប់ឱ្យទូរស័ព្ទដៃ ឬកុំព្យូទ័ររួមការងារចូលមកស្តាប់ មើលអក្សរ និងទាញយកបានភ្លាមៗ។

### ៤. មុខងារភ្ជាប់ Telegram Bot ផ្ញើចេញភ្លាមៗពេលថតចប់
* ភ្ជាប់ជាមួយ Telegram Bot ដោយគ្រាន់តែបញ្ចូល Bot Token និង Chat ID។
* មុខងារ **Auto-Send**: ពេលចុចបញ្ចប់ការថត (Stop & Save) កម្មវិធីនឹងផ្ញើឯកសារសម្លេង សេចក្តីសង្ខេប និងការបកប្រែទៅកាន់ Telegram ឬ Group ភ្លាមៗដោយស្វ័យប្រវត្ត។
* មានប៊ូតុង **Test Connection** សម្រាប់ផ្ទៀងផ្ទាត់ការតភ្ជាប់។

### ៥. មុខងារបម្លែងជាទម្រង់កំណត់ហេតុរដ្ឋបាល (ក្រសួងមហាផ្ទៃ)
* រៀបចំទម្រង់ស្របតាមបទដ្ឋានគតិយុត្ត និងលិខិតរដ្ឋបាលនៃក្រសួងមហាផ្ទៃកម្ពុជា៖
  * **ក្បាលលិខិត**: ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ (Font: Khmer OS Muol Light)
  * **ស្ថាប័ន / ក្រសួង / លេខលិខិត**
  * **ចំណងជើង**: កំណត់ហេតុ ស្តីពី...
  * **កាលបរិច្ឆេទ & ទីកន្លែង**: ថ្ងៃ... ខែ... ឆ្នាំ... នៅសាលប្រជុំ...
  * **សមាសភាពចូលរួម**: អធិបតីភាព, វត្តមាន, អវត្តមាន
  * **របៀបវារៈនៃអង្គប្រជុំ (Agenda)**
  * **ដំណើរការនៃអង្គប្រជុំ និងការពិភាក្សា**
  * **សេចក្តីសម្រេច និងទិសដៅបន្ត**
  * **ហត្ថលេខា**: អ្នកធ្វើកំណត់ហេតុ និងប្រធានអង្គប្រជុំ
* **ទាញយកជា Word (.doc)**: អាចបើកក្នុង Microsoft Word បានភ្លាមៗជាមួយទម្រង់ តារាង និងពុម្ពអក្សរផ្លូវការ។
* **Print / PDF**: អាចបោះពុម្ពចេញលើក្រដាស A4 បានត្រឹមត្រូវ។

## 🚀 របៀបដំណើរការកម្មវិធី (How to Run)

### វិធីទី ១ (ងាយស្រួលបំផុត)៖
គ្រាន់តែចុចពីរដង (Double-click) លើ file៖
```text
start.bat
```
កម្មវិធីនឹងដំណើរការម៉ាស៊ីនបម្រើ និងបើក Browser ទៅកាន់ `http://localhost:3000` ដោយស្វ័យប្រវត្ត!

### វិធីទី ២ (តាមរយៈ Command Line)៖
បើក PowerShell ឬ Terminal នៅក្នុង folder នេះ រួចវាយ៖
```bash
node server.js
```
បន្ទាប់មកបើក Browser ទៅកាន់៖ `http://localhost:3000`

## 🛠️ ឧបករណ៍ទំនើបៗដែលត្រូវបានភ្ជាប់បញ្ចូលក្នុងកម្មវិធី
1. **Opus Realtime Audio Stream Engine**: កូដិកបង្ហាប់សម្លេងទំនើបបំផុតរបស់ IETF ផ្តល់គុណភាពខ្ពស់បំផុត និងទំហំតូចបំផុត។
2. **Web Audio API Analyser**: បង្ហាញរលកសម្លេង Realtime Waveform លើ Canvas ពេលកំពុងថត។
3. **Web Speech Streaming STT**: បម្លែងសម្លេងជាអក្សរខ្មែរភ្លាមៗដោយគ្មានភាពយឺតយ៉ាវ (Zero Latency)។
4. **Google Translate Live Proxy**: បកប្រែភាសាពាក្យសម្តីតាម realtime មិនបាច់ចំណាយថ្លៃ API Key។
5. **Google Gemini Flash AI Integration**: សម្រាប់ជួយកែសម្រួលវេយ្យាករណ៍ និងរៀបចំកំណត់ហេតុរដ្ឋបាលឱ្យកាន់តែឆ្លាតវៃ (អាចបញ្ចូល Key ក្នុងផ្ទាំងការកំណត់)។
6. **Telegram Bot Dispatcher**: ផ្ញើឯកសារសម្លេង (Voice Note/Audio) និងឯកសារកំណត់ហេតុទៅ Telegram ភ្លាមៗ។
7. **QR Code Generator & Local Wi-Fi Sharing**: ចែករំលែកឯកសារទៅទូរស័ព្ទដៃ ឬសហការីរួមការងារតាម Wi-Fi ក្នុងស្ថាប័ន។
8. **Word Administrative Doc Engine**: បង្កើតឯកសារ Word ស្របតាមក្បួនខ្នាតលិខិតរដ្ឋបាលក្រសួងមហាផ្ទៃកម្ពុជា។
